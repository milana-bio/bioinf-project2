# Анализ генома E. coli

## Что это
Учебный проект по биоинформатике. Анализ соотношения количества старт-кодонов к количеству всех других кодонов генома бактерии Escherichia coli (кишечная палочка).

## Что делает
1. Читает геном E. coli из локального файла "ecoli.fasta".
2. Считает количество старт-кодонов генома.
3. Считает общее количество кодонов и вычитает из них старт-кодоны.
4. Строит круговую диагрмамму для визуализации.

## Результаты
- Процентное соотношение количества старт-кодонов к количеству всех других кодонов
- Количество в геноме старт-кодонов ATG: 76282

## Стек
- Python 3.12
- Biopython (чтение FASTA)
- Matplotlib (диаграмма)

## Как запустить
1. Установите зависимости: `pip install biopython matplotlib`
2. Запустите: `python project2.py`
